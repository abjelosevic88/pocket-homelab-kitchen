# Roadmap

Things that would fit, roughly in the order they itch:

- **Pantry photos** — upload here, not only inherit the Inventory one.
- **Recipe scaling by pantry** — "what can I cook right now" filter on the recipes page (the data is already in `GET /recipes/{id}`).
- **Price memory** — remember what a line cost last time and show the expected total before checkout.
- **Firefly III** — match a checkout to the card transaction by date and amount, like Pocket Garage does.
- **Nutrition totals** per day on the plan.
- **Shared read-only list link** for the person who is in the store without an account.
- **Ingredient aliases** ("coriander" = "cilantro") for pantry matching across languages.
- **Pocket Day** — the daily digest app that would read the cook log.
